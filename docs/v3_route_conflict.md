## 2. 왜 계약 기반으로 가는가

### 2.1 §1 의 논거는 A\* 에는 약하게 적용된다

§1 이 시연을 배제한 이유는 **시연이 성능 천장이 되기 때문**이다. 이 논거는
숙련공 시연·기존 CAD 에는 그대로 성립한다 — 사람의 해는 최적이 아니고,
모방하면 그 수준이 상한이 된다.

**A\* 는 다르다.** 단일 배관 경로 문제는 P 이고, A\* 는 그 안에서 **최적해**다.
최적해를 모방하는 것은 천장을 만들지 않는다 — 천장이 곧 최적이다.

천장 문제가 실제로 생기는 곳은 **최적 교사가 없는 n≥2** (서로소 경로 문제, NP-hard)
이고, 계약 기반 계획은 **거기서 RL 을 쓴다.**

> 즉 §1 의 **letter** 와는 충돌하고 **intent** 와는 맞는다.
> 개정 후에도 "숙련공 시연·기존 CAD 금지" 는 그대로 유지한다.

### 2.2 새 노선이 S1-L1 붕괴 원인 (2)를 설계로 해소한다

§19 가 Step 1 붕괴 원인을 두 가지로 특정했다. 그중 **(2) h 드리프트**:

> `h_core` 를 "남은 최적 J" 에 묶어두는 항이 **어디에도 없다.**
> 사전학습 직후 **1.32 kg** → 학습 중 **10~13 kg**. f 순위가 그만큼 망가진다.

그 해법이 S1-N2 였고, **미채택 사유는 기술적 반대가 아니라 §1 철학**이었다.

계약 기반 1단계는 A\* 라벨로 학습한다. 두 경로로 h 가 묶인다:

| 경로 | 효과 |
|---|---|
| 행동 모방 (A\* 선택을 정답으로) | `argmin f` 가 A\* 선택과 맞도록 — **이웃 간 f 순위를 직접 지도** |
| h 회귀 (A\* 잔여 최적 J 를 라벨로) | h 절대값을 "남은 최적 J" 에 묶는다 = **S1-N2 가 1단계 본체가 된다** |

→ **S1-N2 는 "경계선 미채택" 에서 "1단계 설계의 본체" 로 바뀐다.** Lock 해제.

### 2.3 τ 붕괴(원인 1)는 3단계로 이연된다

`추측:` τ 붕괴는 PPO 가 보상을 벌려고 τ 를 줄인 결과였다 (§19-2). 1·2단계는
지도학습이므로 그 압력이 없다. 또 A\* 는 결정적 argmin 이라 1단계에서 τ 가
뾰족해지는 것은 오히려 목표에 부합한다.

→ **S1-N1 (τ 하한 vs 고정) 은 폐기하지 않고 3단계 RL 착수 시점으로 미룬다.**
   1·2단계에서 τ 거동을 계측해 두면 3단계 판단 재료가 된다.

`미결:` 1·2단계에서 τ 가 어디까지 줄어드는지는 미실측.

### 2.4 서포트가 J 에 들어와야 전략 2가 성립한다

다중 배관 조율 전략으로 **전략 2** 가 채택됐다 (`docs/v3_decisions_pending.md` §1.5):

> 각 배관 최단거리를 구한 뒤, 간섭 포인트 회피 + **서포트 병합**으로
> 모든 배관 라우팅을 확보하면서 J_total 이 작은 경로를 구한다.

CLAUDE.md 의 J 에는 **서포트가 없다** (Step 6 미착수, `support_kg` 미확정).
서포트 병합이 핵심인 전략을 서포트 없는 J 위에서 학습시킬 수는 없다.

skeleton 쪽은 이미 다음을 확정했다:

- D79 — 서포트 형식 4종 (A 캔틸레버 · B 브래킷+경사재 · C 문형 1배관 · **D 문형 다배관**)
- 묶임 판정 기준 동결 (같은 면 · 수평 평행 · 축 ±250 mm · 표면 높이 차 ≤ 50 mm ·
  L1·L2 표 범위 · 다리 간섭 없음 · 묶은 무게 < 개별 합 · 좌표 순서 탐욕)
- 공유 서포트 J 귀속 = **얹힌 배관 단위중량(kg/m) 비례** (회계 규약)
- **서포트는 심판이 배치한다.** V3 는 서포트를 출력하지 않고 배관 배치로 묶임을 유도

→ CLAUDE.md 의 `서포트 실중량` Lock 은 **계약으로 해소**된다.

## 5. 개정하지 않는 것

다음은 노선 변경과 무관하게 그대로 간다.

- **숙련공 시연·기존 CAD 를 학습 데이터로 사용 금지** (§1 철학의 본체)
- sb3-contrib MaskablePPO 고정. 자체 PPO 구현 금지 (프로그램 2 실패)
- 그래프 상태 에피소드당 재구성 금지 (프로그램 3 실패)
- 벤딩 반경은 action mask 로만. 보상 항목 금지 (V1)
- 실측 기반 기록 원칙 — `추측:` / `미결:` 태그, 수치에 출처 절번호
- §16·§19 의 실측값 일체
