## 3-1. 라우터 슬롯이 "출발점 집합(나무 전체) → 목표 단자 1개" 를 받을 수 있나

**지금은 못 받는다.** 막는 곳 세 군데:

| 곳 | 지금 | 필요한 것 |
|---|---|---|
| skeleton 슬롯 `router(scenario, pipe, time_limit, placed)` (D49·D50) | 배관 = 단자 2개 | 다리(leg) 단위 호출 — 출발 상태 집합 · 목표 술어 · 다리 구경 |
| `v3/astar_rg.route_rg` | `g.start_state(pipe)` **하나**로 OPEN 을 연다, 목표 = skeleton `is_goal` (end 노드 + 도착 방향) | 여러 출발 상태를 g = 0 (또는 각자 g) 으로 OPEN 에 넣기 — A\* 정의상 쉬운 변경 |
| 소스 패치 (`_search_generic` 선언 줄 문자열 치환) | skeleton 내부 의존 | **D126 공식 인자로 옮긴다** (휴리스틱 인자 · 비용 덧셈 인자). 다중 출발·목표 집합도 같은 공식 경로로 받는 게 맞다 → **skeleton 요청 S-1** |

**출발 상태가 뭔지가 진짜 문제다** (탐색 쪽은 쉽다). 나무 위 점에서 시작하는 다리는 티 규칙(D112)을 지고 시작한다:
티 위치 = 주관 직관 위 · 분기각 ∈ {45, 90} (135 금지, Q2) · 티 중심에서 주관 앞뒤 ≥ 3D_주관, 분기 쪽 ≥ 3D_분기 (Q7) ·
티 = 서포트 고정점 아님, 다리 서포트 간격은 티에서 0 부터 (Q3 (b)). → 출발 상태 = (티 후보 노드, 분기 방향, run, bend, u, 중력 h) 묶음이고,
**어느 노드가 티 후보인지·어떤 방향이 허용되는지는 심판 규칙**이라 skeleton 이 내 줘야 한다 (V3 가 다시 구현하면 D-j 와 같은 어긋남 위험).

⚠️ **D112 와 방향이 반대다.** 이미 확정된 D112 (2026-11-02) 의 순차 근사는 **분기 단자 → 주관 직관 위 목표 집합** (다리 쪽에서 나무로) 이고,
이번 초안 (Takahashi–Matsuyama) 은 **나무 → 단자** 다. 압력관은 대칭이라 상관없지만 **중력관 다리 (flow = in, T7·T8)** 는 흐름이
단자 → 티라 나무에서 출발하면 **흐름 거꾸로** 탐색해야 한다 — 계단식 하향 상태 h (D63, "마지막 하향 이후 수평 누적") 는 앞 방향 정의다.
→ **skeleton 확인 S-2:** 다리마다 탐색 방향 (나무 → 단자 / 단자 → 나무) 을 flow 로 정하는지, 거꾸로 탐색용 중력 규칙을 따로 두는지.

## 3-2. 휴리스틱이 출발점 집합에서도 과대추정 없이 유지되나

| 휴리스틱 | 출발점 집합 (나무 → 단자 1개) | 목표 집합 (단자 → 나무) |
|---|---|---|
| skeleton `h` (D41: 유클리드 × kg/m + 최소 꺾임) | ✅ 그대로 — h 는 (상태, 목표) 함수라 출발이 여럿이어도 admissible·consistent. 다중 출발 A\* = 비용 0 가상 출발점 하나를 둔 A\* | ⚠️ 목표가 선분 집합 → 거리 = 점–나무 최소 거리, 최소 꺾임 항은 도착 방향이 자유(45/90)라 **0 으로 낮춰야** 하한 유지 |
| **rg** (완화 그래프 역방향 Dijkstra) | ✅ 목표 노드가 고정이라 **배관(다리)마다 1회 계산·재사용**이 그대로 된다 (§30.9·§34) | ✅ 티 후보 노드 전부를 씨앗으로 한 번의 역방향 Dijkstra = 정확한 완화 거리. ⚠️ **단 나무가 바뀔 때마다 다시 구해야 한다** (주관이 협상으로 움직이면 목표 집합이 바뀐다) — §34 의 "rg 1회" 가정이 깨진다 |
| CEA (보류 중) | ⚠️ **원래 엄밀 admissible 이 아니다** (q0.05 디코딩, 과대추정 0.2~0.3 % 상태). 출발점 집합 자체는 이걸 바꾸지 않지만 **출발 상태 분포가 학습 분포 밖**이다 — 티 출발 (run = 0 · u = 0 · 분기 방향) 상태를 학습에서 본 적 없음 → 과대추정률 미측정 | ⚠️ 특징이 단일 목표 기준 (`goal_dx/dy/dz` · `goal_dist`, `features.py`) — 목표 집합이면 특징 정의부터 바뀐다 = 재학습 |

결론: **rg 는 두 방향 다 하한을 지킨다** (목표 집합이면 재계산 비용만 생김). CEA 는 출발점 집합 문제와 무관하게 원래 근사이고, 분기에서 쓰려면 재학습·재측정이 필요하다 — 지금은 보류라 2.5단계를 막지 않는다.

## 3-3. 목표가 여럿 (남은 단자 중 가장 가까운 것) — h = min 이냐, 하나씩 지정이냐

- 이론: admissible·consistent 한 h 여럿의 **최솟값도 admissible·consistent** 다. rg 는 남은 목표 전부를 씨앗으로 한 번에 구하면 된다 (K 번이 아니라 1 번).
- **그런데 다리마다 구경이 다르다** (D112: 다리 구경 ≤ 주관, 자기 구경의 r·kg/m·§3.3·서포트 간격·엘보 규칙). 구경이 다르면 **고정층 그래프가 다르고** (D54·D117 캐시 키 = 구경·class·r) 비용도 다르다 → **서로 다른 구경의 단자를 한 탐색의 목표 집합에 넣을 수 없다.**
- **권고: 단자를 하나씩 지정** (순서 = D112 와 같게 — 구경 큰 순, 같으면 나무까지 먼 순). "가장 가까운 것" 다중 목표는 **같은 구경 단자끼리만** 선택 옵션으로 둔다 (속도용, 결과가 순서에 따라 달라지므로 기준선과 같은 규칙이어야 비교가 성립).
- 기록: Takahashi–Matsuyama 는 그래프 Steiner 에서 2-근사다 — 다리마다 A\* 가 최적이어도 **나무 전체는 최적이 아니다.** 이 틈이 V3 학습 몫이 될 수 있다 (D104 "다중 = 품질" 과 같은 자리).
