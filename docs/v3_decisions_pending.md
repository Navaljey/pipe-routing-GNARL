## 1.5 전략 2 (다중 배관 조율)

채택: 각 배관 최단거리를 구한 뒤, 간섭 포인트 회피 + **서포트 병합**으로
모든 배관 라우팅을 확보하면서 J_total 이 작은 경로를 구한다.

기각 (전략 1 = 큰 구경 먼저 + rip-up): ① skeleton 기준선과 동일한 전략 (D50)
② R2 경고 "rip-up 은 기준선 장치" ③ 그 레버는 실측상 효과가 없었다
④ 전략 2 가 전략 1 을 포함한다 (편향 0 이면 퇴화).

### 핵심 제약 — 서포트는 심판이 배치한다 (S1-6 회신)

> V3 는 서포트를 출력하지 않고 **배관 배치로 묶임을 유도**한다

묶임 판정 기준이 **명시적·결정적·동결**됐다 (계약 §b):

```
같은 바닥·천장 면 · 수평 평행 · 축 ±250 mm
지지면 쪽 표면 높이 차 ≤ 50 mm · L1·L2 표 범위
다리 사이 간섭 없음 · 묶은 무게 < 개별 합일 때만 · 좌표 순서 탐욕
```

**이것이 V3 설계를 크게 단순화한다.**

1. **묶임 조건은 학습 대상이 아니다 — 계산 대상이다.** 술어가 결정적이고
   공개돼 있으므로, "묶임 가능 회랑"은 `placed` 에서 결정적으로 유도되는
   **입력 특징**이다. V3 가 추측할 것이 없다.
2. **조율 망이 결정할 것은 하나뿐** — "그 묶음을 쫓기 위해 길이·꺾임을
   지불할 가치가 있는가".
3. **유인이 단조다.** "묶은 무게 < 개별 합일 때만" 이므로 심판이 V3 에게
   불리하게 묶는 일이 없다. 묶임 자체는 항상 이득이고, 비용은 거기 가려고
   지불하는 길이·꺾임뿐. 학습 난이도가 크게 낮아진다.

### 귀결

| # | 귀결 | 상태 |
|---|---|---|
| 1 | 비용 편향 채널을 둔다 | ✅ 확정 (형태 = D-i, 권고 (ii) 강화) |
| 2 | 라우터 비용 함수를 V3 가 재설계한다 — 묶임 술어를 비용에 반영 (D57 은 놓인 배관을 무시) | ✅ 확정 |
| 3 | 조율 망 출력 = 놓인 배관별 매력도 스칼라 (배관 수만큼) | ✅ 확정 |
| 4 | 3단계 보상 = **검증기 `J_total` 직접** (배관별 J 아님) | ✅ 확정 — D-j 해소 |

### ~~D-k 공유 서포트 J 귀속 규칙~~ → 해소 (skeleton 회신)

**규칙:** 공유 서포트 무게는 얹힌 배관 **단위중량(kg/m) 비례**로 배관별 J 에

## 1.7 R7 — 심판이 V3 에 넘긴 과제 (신규 2026-10-20)

> 남은 부재 막힘 18건은 모두 "먼저 놓인 배관이 나중 배관의 서포트 자리를 막는" 경우
> → **R7 (랙 형성·서포트 공유, V3 과제)**

심판은 D89(막히면 함께 받침) · D90(부재 예약)으로 **46 → 18 건**까지 줄였다.
남은 18건은 **사후 보정으로 원리적으로 못 푼다** — 순차 배치는 앞을 내다보지 못한다.

| | 할 수 있는 것 | R7 18건 |
|---|---|---|
| 기준선 (순차 + 사후 정렬) | 이미 놓인 것을 보고 고친다 | ❌ **불가** |
| **전략 2 (사전 선택)** | 놓기 전에 자리를 고른다 | ✅ 겨냥 가능 |

### 이것이 전략 2 의 차별점을 복원한다

2026-10-18 에 "묶음 정렬로 기준선이 강해져 전략 2 의 차별점이 좁아졌다" 고 적었다.
그 판단은 **R7 로 뒤집힌다** — "사후 보정 vs 사전 선택" 의 차이가
**측정 가능한 18건**으로 나타났고, 이는 D77 ①(완전 성공 시나리오 수)에 직접 걸린다.

**Layer 0 통과 (PR #28 첫 해, 기준선):** 기본 169 → **176** · 밀집 30 118 → **129** ·
밀집 50 185 → **195**. 최종 판정 곡선은 **S1-8 동결 측정분**.

### D-i 설계에 주는 함의 — ⚠️ 한계가 드러난다

R7 은 "뒤에 올 배관을 위해 자리를 비워라" 를 요구한다. 그런데 D-i 권고 (ii) 의
매력도는 **이미 놓인** 배관에 대한 신호다.

- **첫 배관은 아무 신호 없이 놓인다.** 첫 배관이 나쁜 자리에 가면 뒤가 전부 꼬인다
- 매력도만으로 "비워 두기" 가 표현되는지 `미결:`

조율 망이 **순서**로도 푸는 길이 있다 (큰 구경을 먼저 놓고 작은 것을 붙이는 식).
(ii) 는 순서 + 매력도를 함께 내는 전제였으므로 성립할 수 있다. **D-i 설계 시
R7 18건을 시험 사례로 삼아 확인한다.**

**단 D-o 가 선행이다.** 비공개 표 없이 만든 라벨은 전부 폐기된다.

**3단계는 세 가지를 기다린다** — 순차 배치 라벨 해법, 묶음 규칙 구현, S1-8 새 곡선.

### ★ D-n. `placed` 를 어느 관측 채널에 넣는가  *(신규 2026-10-17)*

**freeze 시점의 라우터가 `placed` 를 본 적이 없다.**

1·2단계는 단일 배관이고, D86 으로 풀린 것은 **빈 맵** 단독 라벨이다. 그런데 3단계에서
조율 망은 `placed` 가 채워진 상태로 라우터를 부른다. 계약 §(e2) 가 2단계 망을
**freeze** 하라고 하므로, freeze 된 망에게 그 입력은 **분포 외**다.

**관측 설계로 해결된다 — `placed` 의 두 역할을 분리한다.**

| `placed` 의 역할 | 들어갈 곳 | 1·2단계에서 |
|---|---|---|
| **기하** — 장애물 + 이격 r₁+r₂ | **고정 장애물과 같은 채널** | 그냥 장애물로 학습된다 ✅ |
| **묶임 기회** | **D-i 매력도 채널** | 0 으로 채운다 ✅ |

같은 채널에 넣으면 3단계의 `placed` 는 "장애물이 더 많은 맵" 일 뿐이고 분포 외가 아니다.
별도 채널로 구분하려 들면 **순차 배치 맥락 라벨**이 필요해지고, 그것은 지금 막혀 있다
(skeleton: 서포트 부재 자리 막힘 해법 결정 중 — 기본 9 · 밀집 50 21건).

→ **D-i (ii) 안과 맞물린다.** 기하는 결정적으로 계산, 묶임 의도는 조율 망이 주입.

#### 권고

`placed` 를 고정 장애물 채널에 합친다. 이유:

1. 1·2단계 빈 맵 라벨로 충분하다 — **순차 배치 맥락 라벨 대기가 1·2단계를 막지 않는다**
2. 3단계에 분포 외 입력이 없다
3. 라우터가 잃는 정보("이건 배관이라 묶을 수 있다")는 D-i 채널이 담당한다

### D-d. "큰 맵 × 다중 배관" 공백  *(기한: E2 생성 전)*

- 2단계 = 큰 맵 × **단일** (E2) / 3단계 = 보통 맵 × **다중** (E1 밀집)
- → **큰 맵 × 다중**을 보는 단계가 없다

3단계에서 라우터가 freeze 되므로 큰 맵 능력은 2단계에서 검증됐다고 볼 수도 있으나,
조율 망이 큰 맵에서 같은 성능을 내는지는 별개다. 배관 수가 같아도 맵이 커지면
경합 구조가 달라진다.

정할 것: (a) 3단계 평가에 추가 / (b) 4단계 E3 에서 함께 / (c) 범위 밖.

### D-e. 실제 블록 데이터 — 대표성 확인 수단  *(기한: E2 생성 전)*

- E1 "수작업" 세트가 실제 블록 유래인지 가상 구성인지 명시
- 실제 블록 데이터 확보 가능 여부, 몇 개 블록 분량
- **대표성 판정 지표** — 장애물 밀도 분포? 배관 수? start-goal 거리 분포? 굴곡도?
- 합격선 — 생성 시나리오가 실제 블록 분포를 어느 정도 덮어야 하는가
- 실제 블록을 최종 평가 전용으로 쓸 것인가, 일부를 학습에 넣을 것인가 (누수 방지)

이것이 없으면 모든 성능 수치가 "우리가 만든 시나리오에서만 잘한다"로 귀결된다.

### D-f. 모방 → 강화학습 전환의 실측 근거

경계는 "다중 배관"으로 확정. 남은 것: **"A\* 라벨 생성이 너무 비싸다"의 실측 기준.**
A\* 1회 계산이 몇 초를 넘으면 오프라인 라벨 생성을 포기하는가. 2단계 실측 필요.

**★★ D-o 가 모든 라벨 작업의 선행 조건** — 비공개 서포트 표 없이 만든 라벨은
전부 폐기된다. skeleton 이 바로 이 사고를 당했다(PR #26). **소유자 조치가 필요하다.**

**D-m ② 가 급해졌다** — `support_standard.source == "private"` 와 sha256 확인을
하드 스톱에 넣는다. 환경 변수 누락은 **조용히** 통과한다.

**D-n 이 D-i 보다 먼저** — `placed` 를 어느 채널에 넣느냐가 정해져야 D-i 매력도
채널의 의미가 확정된다. 권고(장애물 채널 합침)를 택하면 둘이 깔끔히 분리된다:
기하는 계산, 묶임 의도는 조율 망.

**D-j 는 해소됐다 (2026-10-18)** — 증분 검증 0.56 s 로 검증기 직접 사용이 성립한다.
술어 복제 권고는 철회. D-m ③ 은 보류.

**D-e·D-d 는 E2 생성 전** · **D-a/D-b 는 S1-8 새 곡선 실측 후**
· **D-f 는 2단계 실측 후**.

**블록 쌍 라벨 생성 시점.** 통보: *"S1-6b·S1-7 은 **단일 블록** A\* 결과를 바꾸지 않음"*

E1 에는 **블록 쌍**이 포함되는데(경계 관통점) 위 문장은 단일 블록에 대한 보장이다.

맞다면 1단계 학습을 (a) 단일 블록만으로 먼저 돌리고 블록 쌍을 나중에 추가 학습 /
