# D-n 설계안 — 라우터 입출력: `placed` 처리와 편향 주입 지점

**작성:** 2026-10-20 · **상태:** 설계안 (승인 전)
**해결:** D-n (`placed` 관측 채널) · D-i 의 전제 재정의

> 계약 §(c) 범위다 — 슬롯 **내부**의 관측·망 구조·탐색 전략은 V3 가 정한다.
> 심판은 `RouteResult` 만 본다.

---

## 0. 결론

**관측 벡터를 바꾸지 않는다.** 76차원 그대로다.

| 무엇 | 어디로 | 효과 |
|---|---|---|
| `placed` 의 **기하** (장애물 + 이격 r₁+r₂) | **점유 격자** | `obs[34:76]` 이 자동 반영. 벡터 불변 |
| 조율 망의 **병합 매력도** | **비용 `ΔJ`** (관측 아님) | `f` 순위만 바뀐다. 망 불변 |

→ 1·2단계에서 학습한 망이 **그대로** 3단계 라우터가 된다. 입력도 가중치도 안 바뀐다.

## 1. `placed` 는 점유 격자로 들어간다

### 1.1 계약이 이미 의미를 고정했다

> §(a) 라우터는 놓인 배관 `placed = [(Pipe, waypoints)]` 를 **장애물로 본다.**
> 이격은 r₁ + r₂ (D17, D50②)

V3 가 정할 것은 "어떻게 인코딩하느냐" 뿐이다.

### 1.2 이미 그렇게 돼 있다

CLAUDE.md §2 Layer 0:

```
충돌 (장애물·기존 파이프) | mask | v2 기존
```

v2 가 이미 기존 파이프를 점유 격자에 넣어 마스킹했다. **새 설계가 아니라 확인이다.**

### 1.3 구체

```
점유 격자 pad  =  고정 장애물  ∪  { placed 배관을 (r₁ + r₂) 로 팽창한 영역 }

                 r₁ = 지금 라우팅 중인 배관 반경
                 r₂ = 각 placed 배관 반경
```

이러면 다음이 **전부 자동으로** 따라온다.

| | 경로 |
|---|---|
| `obs[34:40]` 이웃 6면 SDF | `free3(pad, ·)` |
| `obs[40:50]` SDF 센서 10개 | `free3(pad, ·)` |
| `obs[50:76]` 26방향 자유 직진 길이 | `free3(pad, ·)` |
| `action_masks()` 충돌 회피 | `free3(pad, ·)` |
| `is_valid_turn()` lookahead k | `free3(pad, ·)` |

**관측도 마스킹도 한 줄 안 고친다.** 라우터에게 3단계 맵은 "장애물이 더 많은 맵"일 뿐이고,
그건 1·2단계에서 질리도록 본 분포다. **분포 외 입력이 없다.**

### 1.4 팽창은 배관 1개당 1회 — 스텝마다가 아니다

`r₁` 이 라우팅 중인 배관 구경에 따라 달라지므로, 같은 `placed` 라도 배관마다 팽창이 다르다.
→ **배관 하나를 라우팅하기 시작할 때 한 번** 격자를 만든다.

> ⚠️ §12 의 금지 항목과 혼동하지 말 것.
> **금지:** 그래프 상태를 **매 step** 재구성 (O(노드×장애물), 프로그램 3 실패)
> **여기:** **배관당 1회**. skeleton 파이프라인도 D11 로 배관마다 그래프를 재생성한다

`미결:` 밀집 50 에서 배관 50개 × 격자 팽창 비용이 얼마인지 **미실측**.
라벨 생성·3단계 학습 비용에 들어가므로 1단계 착수 시 함께 잰다.

## 2. 매력도는 관측이 아니라 비용으로 들어간다

### 2.1 발견 — freeze 와 zero-padding 이 충돌한다

처음 설계는 "D-i 채널을 `obs` 뒤에 붙이고 1·2단계는 0으로 채운다" 였다 (§8 전이 규칙).
**이것은 작동하지 않는다.**

```
zero_pad_state_dict()  → 새 입력 차원의 가중치를 0 으로 둔다
계약 §(e2)             → 3단계에서 2단계 망을 freeze 한다
                        ↓
          0 으로 둔 가중치가 학습되지 않는다
                        ↓
          새 채널은 영원히 무시된다 = 죽은 입력
```

세 가지 길이 있었다.

| 안 | 내용 | 판정 |
|---|---|---|
| A | 1·2단계부터 채널에 실제 값을 섞어 학습 | 1·2단계에 없는 개념을 억지로 넣는다. 라벨도 없다 |
| B | 3단계에서 입력층만 freeze 예외 | 계약 §(e2) "라우터로 고정" 과 긴장. E1 회귀 보장이 약해진다 |
| **C** | **매력도를 `ΔJ` 에 더한다** | ✅ **채택** |

### 2.2 채택 — `ΔJ` 에 더한다

§6 의 GNARL 구조에서 **행동을 가르는 것은 `ΔJ + h(s')`** 이다
(`g` 는 이웃 공통이라 softmax 에서 상쇄된다).

```
1·2단계 :  f(n) = g + ΔJ(n)                        + h(s')
3단계   :  f(n) = g + ΔJ(n) + bias(n, placed, a)   + h(s')
                              └────── 결정적 함수. 학습 파라미터 아님
```

`a` = 조율 망이 내는 **놓인 배관별 매력도 스칼라** (D-i 권고 (ii)).

```
bias(n, placed, a)  =  − Σ_p  a_p · merge_indicator(n, p)
                                    └── 묶임 술어로 계산. 결정적·공개 (계약 §b)
```

### 2.3 왜 이게 맞는가

| | |
|---|---|
| **망을 안 건드린다** | `h_net` freeze 그대로. 가중치 한 개도 안 바뀐다 |
| **입력을 안 바꾼다** | 분포 외 없음. zero-padding 불필요 |
| **1·2단계와 동일** | `bias ≡ 0` 이면 기존 식 그대로. 회귀가 **구조적으로** 보장된다 |
| **조율 망이 가볍다** | 출력이 배관 수만큼의 스칼라뿐 |
| **묶임은 계산한다** | 이미 정한 원칙 — "학습 대상이 아니라 계산 대상" |

**D-i 의 전제가 바뀐다.** "1단계에서 입력 자리를 비워두지 않으면 3단계에서 재학습" 이라는
걱정이 **사라진다** — 입력을 안 바꾸기 때문이다.

### 2.4 한계 — 짚어둔다

**`bias` 는 `h` 를 바꾸지 못한다.** `h(s')` 는 "남은 최적 J" 의 추정이고 freeze 돼 있다.
즉 라우터는 *"지금 이 칸으로 가면 묶임에 가깝다"* 는 **단기 편향**만 받고,
*"이쪽으로 가면 나중에 묶기 좋다"* 는 **장기 가치**는 못 본다.

`추측:` 묶임 조건이 축 ±500 mm · 높이 차 ≤ 50 mm 로 **국소**하므로 단기 편향으로
충분할 수 있다. **미실측.**

못 미치면 선택지:

- `bias` 를 전방 k칸 lookahead 로 확장 (여전히 결정적, 망 불변)
- 안 C → B 로 후퇴 (입력층만 해제). 계약 §(f) 보고 필요
- 조율 망이 **순서**로 더 많이 풀도록 (R7 과 같은 방향)

### 2.5 ⚠️ 미결 — `bias` 의 크기

`ΔJ` 와 같은 단위·스케일이어야 한다 (정규화 J). 너무 크면 라우터가 경로를 포기하고
묶임만 쫓는다. 너무 작으면 아무 일도 안 일어난다.

| 참조 | 값 |
|---|---|
| 이웃 간 `f` 표준편차 (50×50×20) | **0.0303** (§6) |
| 엘보 1개 = 직진 4.7칸 | **−0.064** (§19-3) |
| τ = 0.05 에서 logit 폭 | ≈ 0.61 |

`미결:` `a_p` 의 범위를 어디로 둘지. 엘보 1개(0.064)를 상한의 기준점으로 삼는 것이
자연스러워 보이나 **미실측**. D-i 에서 정한다.

## 3. R7 과의 관계 — 한계가 여기서도 드러난다

R7(랙 형성)은 *"뒤에 올 배관을 위해 자리를 비워라"* 를 요구한다. 그런데 `bias` 는
**이미 놓인** 배관에 대한 신호다.

→ **첫 배관은 `bias ≡ 0` 으로 놓인다.** 첫 배관이 나쁜 자리에 가면 뒤가 전부 꼬인다.

남은 길은 **순서**다. 조율 망이 배치 순서를 정하므로, "큰 구경을 먼저 놓고 작은 것을
붙인다" 같은 전략은 표현된다. R7 18건이 그걸로 풀리는지가 **D-i 설계의 판정 기준**이다.

→ **skeleton 에 R7 18건의 시나리오·배관 식별자를 요청한다.** 목록 없이는 설계가
겨냥했는지 확인할 수 없다.

## 4. 확정 / 미결

### 확정 (이 문서로 정함)

```
[확정] placed 기하 → 점유 격자에 (r₁+r₂) 팽창. 관측 벡터 76차원 불변
[확정] 팽창은 배관 1개당 1회 (매 step 아님 — §12 금지 항목과 구분)
[확정] 매력도 → ΔJ 에 더하는 결정적 bias. 관측·가중치 불변
[확정] bias ≡ 0 이면 1·2단계와 완전히 동일 → 회귀가 구조적으로 보장
[확정] D-i "입력 자리 미리 비워두기" 걱정은 폐기 — 입력을 안 바꾼다
```

### 미결

```
[미결] bias 의 크기 범위 (a_p)                → D-i, 엘보 0.064 를 기준점 후보로
[미결] 단기 편향만으로 충분한지               → 3단계 실측
[미결] 배관당 격자 팽창 비용 (밀집 50)        → 1단계 착수 시 측정
[미결] R7 18건을 순서만으로 풀 수 있는지      → 목록 수령 후 D-i
```
