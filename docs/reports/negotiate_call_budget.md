## 조건

- **시나리오:** 섹션 3) `docs/reports/opt_stage1_valsets.json` 밀집 30·50 각 5 (시드 = E1 시드 + 20,000,000). 생성·저장 파일 sha256 = manifest **10/10 일치** (맵마다 측정 직전 대조).
- **출발점 (반복 1):** 다른 배관 단자 예약(D59)을 지킨 단독 경로 = OPT.Dec6 정의. 가격 0.
- **라우터:** 컴파일 A\* (skeleton `astar_fast._search_generic` 선언 패치) + max(h, rg) × **1.1**, 상한 2²². rg = **배관별 1회** (빈 그래프 + 단자 예약) 계산, 반복 내내 재사용. 반복 1 실패 배관(경로 없음·상한 소진)은 다시 부르지 않는다.
- **협상:** 다른 배관 경로가 표시(D67 항목)를 남기는 엣지에 `길이 × kg/m × (pres + hist)` 를 더한다 — pres 0.5 (반복 2) ×1.5/반복, hist +0.3/충돌 반복 (`추정:`, 튜닝 안 함). 변형 **(C) 충돌 배관만** 다시 깐다. 같은 반복 안 갱신 가격 즉시 반영 (D50 순서). 멈춤 = 충돌 0 또는 반복 15. 충돌 판정 = `multi.routes_conflict`.
- **라우팅 벽시계** = 호출마다 그래프 생성 + 가격 표시 + rg + 탐색 (충돌 판정·채점 제외). **누적 벽시계** = 전부 포함.
- **머신:** Intel Xeon @ **2.30 GHz** (밀집 30 전부 · 밀집 50 _000·_001) / **2.10 GHz** (컨테이너 재시작 후 밀집 50 _002~_004) · 보이는 코어 2 · RAM 7 GB · Python 3.13.18 · numba 0.68.1 · numpy 2.5.3. **작업자 1** (단일 프로세스·단일 스레드, D122 시나리오당 2 코어 안). ⚠️ E1 측정 머신 (2.80 GHz · 4 코어) 과 다르다 — 시간은 E1 머신보다 길게 나왔을 것 (`추정:`).
